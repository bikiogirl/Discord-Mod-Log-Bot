# 🛡️ Discord Mod & Log Bot

A powerful Discord moderation and activity logging bot designed to keep your server safe and organized. Features automated tracking, timeout management, kicking, and banning capabilities.

## ✨ Features

- 📜 **Audit & Server Logs:** Keeps detailed records of member activities and server events.
- ⏱️ **Timeout / Mute System:** Easily apply temporary timeouts to users.
- 🔨 **Moderation Actions:** Perform quick kicks and bans with reason logging.
- 🔐 **Secure & Lightweight:** Built with Python for high stability and fast response times.

## 🛠️ Commands

| Command | Description |
| :--- | :--- |
| `/timeout <user> <duration> [reason]` | Temporarily mute/timeout a user. |
| `/kick <user> [reason]` | Kick a user from the server. |
| `/ban <user> [reason]` | Ban a user permanently from the server. |
| `/unban <user_id>` | Remove a ban from a user. |
